# 주제 검토 (2026-07-29)

## 원안: 네이버 검색 트렌드로 제도 사각지대 탐지

> 네이버 검색 데이터를 추출해 최신 트렌드를 파악하고, 이를 통해 현 제도의 문제점·허점·사각지대를 찾아 선제 대응하는 프로그램

### 문제의식은 좋다
"데이터로 제도의 사각지대를 찾는다"는 목표 자체는 공고문의 *"인사이트 탐색, 정책제안"* 과 정확히 맞물린다. 버릴 것은 아이디어가 아니라 **측정 도구(검색량)** 다.

### 치명적 결함

**① 인과관계 부재 (팀 내부에서 이미 지적)**
- 검색량 ↑ = 단순 화제성일 수 있음 (연예/사건 이슈)
- 검색량 ↓ = 제도가 충분해서 문제가 없을 수도 있음
- 즉 검색량은 *관심도*의 대리변수이지 *제도 결함*의 대리변수가 아니다

**② 네이버 데이터랩은 절대 검색량을 제공하지 않음**
- 오픈 API는 조회 기간 내 최댓값을 100으로 정규화한 **상대 지수**만 반환
- 키워드 그룹 간 절대 비교 불가 → "어느 제도가 더 심각한가" 순위 산정이 원천 불가능
- 이 아이디어의 핵심 기능이 데이터 사양 때문에 성립하지 않음
- (참고: 절대 검색수는 네이버 *검색광고* 키워드도구 API에서 월 단위로만 제공 — 장기 시계열 불가)

**③ 발견이 아니라 확인 구조**
- 검색어를 조회하려면 키워드를 사람이 먼저 지정해야 함
- 사각지대를 이미 알아야 그 키워드를 넣을 수 있음 → 새로운 발견이 나올 수 없는 구조
- 심사 질의 "데이터로 새로 발견한 것이 무엇인가"에 답하기 어려움

**④ 정답 라벨(ground truth) 부재 → 모형 검증 불가**
- 빅데이터 분석 부문 채점의 뼈대는 예측 모형의 성능 검증
- 정답이 없으면 정확도/재현율을 제시할 수 없음 → 결과의 타당성을 아무도 확인 못 함

**⑤ 데이터 규모가 빅데이터 수준이 아님**
- 키워드 5개 × 일별 시계열 ≈ 수천 행. 처리 난이도 어필 불가
- 검색량 급등은 대부분 언론 보도의 후행 지표 → 결론이 "보도 많으면 검색 많다"로 수렴할 위험

### 살리는 방향
검색량을 **유일한 근거**에서 **수요 신호 중 하나**로 강등시킨다.

```
수요(need)  : 인구 구조, 이용 실적, (보조) 검색 트렌드
공급(supply): 시설 위치, 정원, 접근성
사각지대     = 수요 대비 공급의 괴리(mismatch)
```
이렇게 재정의하면 행정 데이터로 검증이 가능해지고, 팀원의 문제의식도 그대로 계승된다.

## 대안

### ⭐ A안 (추천): 의료 사각지대 지도 + 최적 입지 제안

| 항목 | 내용 |
|---|---|
| 문제 | 소아과·분만·응급 등 필수의료 접근성이 취약한 지역이 어디인가 |
| 데이터 | 심평원 전국 병·의원 위치/진료과목, 행안부 읍면동 연령별 인구, 대중교통 정류장, **국립중앙의료원 헬스맵 공식 의료취약지 지정 현황** |
| 방법 | 격자 단위 접근성 계산(최근접 시설 소요시간) → 인구 대비 공급 밀도 → 사각지대 지수 → 분류 모형 → 신규 시설 최적 입지 탐색(시설입지 최적화) |
| **검증** | **헬스맵 공식 취약지 지정을 정답 라벨로 사용** → 재현율/정밀도 산출 가능 |
| 킬러 메시지 | 공식 지정에서 누락됐지만 모형이 위험으로 판정한 지역 = **새로 발견한 사각지대** |
| 산출물 | 인터랙티브 지도 → 5분 시연 영상에 최적 |

- 결함 ①③④를 모두 해소한다. 원안의 문제의식은 유지된다.
- 검색 트렌드("소아과 오픈런" 등)를 지역별 수요 보조 신호로 얹으면 팀원 아이디어도 살아남는다.
- 데이터 출처: https://www.data.go.kr/data/15154171/fileData.do

### B안: 폭염 취약계층 사각지대 (시의성 최고)

| 항목 | 내용 |
|---|---|
| 문제 | 무더위쉼터가 실제 폭염 취약계층 분포와 어긋난 지점은 어디인가 |
| 데이터 | 무더위쉼터 표준데이터, 기상청 ASOS/AWS 관측, 읍면동 고령인구, 건물 노후도, 녹지 비율 |
| 방법 | 폭염 노출도 × 취약도 → 위험 지수 → 쉼터 커버리지와 대조 → 미커버 고위험 구역 도출 |
| 장점 | 8월 심사라 시의성이 압도적. 데이터 전부 즉시 다운로드 가능 |
| 약점 | 정답 라벨이 A안만큼 깔끔하지 않음 (온열질환 발생 통계로 일부 대체 가능) |

### C안: 상권 폐업 위험 조기경보

| 항목 | 내용 |
|---|---|
| 데이터 | 서울시 상권분석서비스 (추정매출/점포/유동인구/집객시설, 분기별 수십만 행) |
| 방법 | 점포 수 변화로 폐업 라벨 생성 → 다음 분기 폐업 위험 예측(XGBoost) → SHAP 요인 해석 |
| 장점 | 데이터 규모가 진짜 빅데이터급, 시계열 홀드아웃 검증이 깔끔 |
| 약점 | **유사 프로젝트가 매우 흔함** → 창의성 점수에서 불리 |
| 출처 | https://data.seoul.go.kr/dataList/OA-15572/S/1/datasetView.do |
