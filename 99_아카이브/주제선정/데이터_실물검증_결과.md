## ⚠️ A안 — 접근은 가능하나 실물 미검증

| 대상 | HTTP | 상태 |
|---|---|---|
| 공공데이터포털 (data.go.kr) | 200 | 정상 |
| 헬스맵 데이터셋 페이지 | 200 | 정상. **CSV 내용 미확인** |
| 심평원 오픈데이터 포털 | 200 | 정상. 페이지에 **"로그인"** 문자열 존재 → 다운로드 시 로그인 요구 정황 |
| 국가법령정보센터 (고시) | 200 | 정상 |
| 행안부 주민등록 인구통계 | 200 | 정상 |

**평가**
- 승인·심의 절차가 필요한 데이터는 없으므로 **확보 가능성 자체는 높다**
- 다만 파일데이터는 로그인 후 다운로드 → **자동 검증 불가**, 사람이 직접 받아 열어봐야 함
- 헬스맵 CSV의 실제 컬럼(소아청소년과 취약지 플래그, 시군구 코드)은 **여전히 미확인**
- 심평원 zip의 좌표·전문의수 컬럼도 **미확인**

> **"확보 가능성이 높다"와 "확보가 확인되었다"는 다르다.**
> 현재 A안은 전자, D안은 후자다.
