## 0. 이 대회에서 "좋은 주제"의 조건

공고문에서 직접 도출한 판단 기준 5가지. 이후 모든 안은 이 기준으로 평가한다.

| # | 조건 | 근거 (공고문 문구) |
|---|---|---|
| 1 | **예측 모형 또는 인사이트 탐색이 성립** | *"기계학습, 통계분석 등을 이용한 예측 모형 개발, 인사이트 탐색"* |
| 2 | **정책 제안으로 연결** | *"정책제안 등 창의적인 빅데이터 분석"* |
| 3 | **창의성이 결과물에 드러남** | 전 부문 공통으로 *"창의적"* 반복 강조 |
| 4 | **5분 영상으로 보여줄 것이 있음** | 시연/발표 동영상이 필수 제출물 |

여기에 문서화되지 않은 실질 조건이 하나 더 있다.

> **6. 결과가 맞는지 확인할 방법(정답 라벨)이 있어야 한다.**
> 이것이 없으면 모형을 만들어도 성능을 제시할 수 없고, 심사위원은 결과를 신뢰할 근거가 없다.
> 팀원 원안이 무너진 지점이 정확히 여기다.

## A안 (추천): 현행 의료취약지 지정 제도의 사각지대 탐지

### A-1. 이 주제의 핵심 발상

일반적인 접근은 "의료 취약지가 어디인지 찾자"이다. 이건 이미 정부가 하고 있다.

우리는 한 단계 위로 올라간다.

> **"의료 취약지를 판정하는 제도 자체가 무엇을 놓치고 있는가?"**

분석 대상이 *현상*이 아니라 *제도*다. 이 메타적 전환이 창의성 점수의 핵심이며,
동시에 팀원이 원래 하고 싶었던 **"제도의 허점·사각지대를 선제적으로 발견한다"** 는 목표와 정확히 일치한다.

### A-2. 문제가 실재한다는 근거 (중요 — 이게 있어서 주제가 성립한다)

현행 보건복지부 의료취약지 지정 제도는 **2차 의료기관까지의 이동 소요시간**을 핵심 기준으로 삼는다.
응급의료 분야의 경우 지역응급의료센터 30분 내 또는 권역응급의료센터 60분 내
접근 불가능 인구가 **27% 이상**인 지역을 취약지로 지정한다
([보건복지부 고시 제2024-261호](https://www.mohw.go.kr/board.es?mid=a10107010000&bid=0043&act=view&list_no=1484143)).

이 기준의 문제가 이미 공개적으로 지적되고 있다
([의협신문](https://www.doctorsnews.co.kr/news/articleView.html?idxno=156913), [한의신문](https://akomnews.com/bbs/board.php?bo_table=news&wr_id=64510), [청년의사](http://www.docdocdoc.co.kr/news/articleView.html?idxno=3032113)):

1. **2024년 8월 기준 지정된 111개 의료취약지 중 106개(95.5%)가 소멸위험지역**
   → 제도가 사실상 "인구 적은 농어촌"만 포착하고 있다는 정황
2. **이동 소요시간은 짧으나 진료 대기시간이 길어 실질 접근성이 낮은 도시 지역이 애초에 지정 대상에서 배제**
   → 명시적으로 지적된 **제도의 사각지대**
3. 이동 소요시간 기준 자체가 임의적으로 설정되어 실제 의료접근성을 반영하지 못함
4. 개선방안으로 **"진료 대기시간·의료기관당 인구수 등 상대적 비교 고려"** 가 제안되고 있음

> **핵심**: 문제제기는 언론과 국회에서 이미 나왔지만, **이를 전국 단위 데이터로 정량 입증한 분석은 없다.**
> 우리가 채울 빈칸이 명확하다. 심사위원에게 "왜 이 주제인가"를 설명할 때 이 근거를 그대로 쓰면 된다.

### A-3. 가설

> 현행 제도는 **거리(이동시간)** 만 본다.
> 실질 의료접근성은 거리뿐 아니라 **혼잡도(수요 대비 공급)** 에 좌우된다.
> 따라서 거리 기준으로는 정상이지만 혼잡도 기준으로는 취약한 지역 —
> **"도시형 의료취약지"** — 가 제도의 사각지대로 존재한다.

### A-5. 분석 파이프라인 (단계별 전개)

```
[1] 공간 단위 확정
    시군구(약 250개) = 기본 단위 (정답 라벨이 시군구 단위이므로)
    읍면동(약 3,500개) = 세부 진단용

[2] 공급 지표 산출
    시군구별 · 진료과목별 전문의 수 / 병상 수 / 기관 수
    ※ 심평원 원자료 약 10만 기관 → 공간 조인 + 집계

[3] 수요 지표 산출
    진료과목에 대응하는 대상 인구를 정확히 매칭
      소아청소년과 → 0~14세 인구
      산부인과(분만) → 가임기 여성 인구
      응급의료      → 전체 인구 + 65세 이상 가중

[4] 실질 접근성 지수 산출  ★ 방법론의 핵심
    2SFCA (Two-Step Floating Catchment Area) 기법 적용
      1단계: 각 의료기관의 공급량 ÷ 도달권 내 수요 인구  → 기관별 공급-수요비
      2단계: 각 지역에서 도달 가능한 기관들의 공급-수요비 합산
    → 거리와 혼잡도를 동시에 반영하는 보건지리학 표준 기법
    → 현행 제도의 "단순 이동시간"과 정면 대비되는 지표

[5] 현행 제도 재현 모형
    공식 지정 취약지(111개)를 정답 라벨로 하는 분류 모형 학습
    SHAP으로 변수 기여도 해석
    → "제도는 사실상 인구밀도·소멸위험도만 보고 있다"를 정량 입증
    → 여기서 나오는 수치가 보고서의 하이라이트

[6] 사각지대 도출
    실질 접근성 지수 하위 구간  ∧  공식 지정 목록에 없음
    = 제도가 놓친 지역 (False Negative 후보)

[7] 외부 검증  ★ 이 단계가 있어야 주장이 성립한다
    후보 지역이 실제로 문제가 있는지 독립 데이터로 확인
      · 관외 의료이용률 (타 지역 원정 진료 비율)
      · 헬스맵의 기준시간내의료이용률(TRI)
      · 지역별 검색 트렌드("소아과 오픈런", "야간진료" 등)  ← 팀원 원안이 여기서 살아난다

[8] 정책 제안
    · 대안 지정 기준 제시 (이동시간 + 혼잡도 복합 지표)
    · 신규 시설 배치 우선순위 (max-coverage 탐욕 알고리즘)
```

### A-6. 산출물

- 전국 실질 의료접근성 인터랙티브 지도 (folium 또는 kepler.gl)
- **현행 지정 vs 우리 지수 비교 대시보드** — 5분 영상의 클라이맥스
- 제도가 놓친 사각지대 Top N 리스트 + 각 지역별 근거
- 대안 지정 기준 제안서 (고시 개정안 형태)

### A-7. 심사기준 충족 근거

| 심사 항목 | 이 주제가 어떻게 충족하는가 |
|---|---|
| **창의성** | 현상이 아닌 **제도를 분석 대상으로 삼는 메타적 전환**. 취약지를 찾는 분석은 흔하지만, 취약지 *판정 기준의 오류*를 정량화한 분석은 사실상 없다. 언론·국회의 문제제기는 있으나 데이터 검증이 비어 있는 지점을 정확히 공략 |
| **분석방법 타당성** | 2SFCA는 보건지리학의 확립된 표준 기법 → 방법 선택에 대한 방어 논리가 확실. 분류 모형 + SHAP으로 해석력 확보. **정답 라벨이 있어 정밀도·재현율 제시 가능** |
| **데이터 활용도** | 약 10만 개 요양기관 × 진료과목 × 3,500 읍면동 공간 조인. 6종 이종 데이터 결합. 규모와 전처리 난이도 모두 확보 |
| **결과 유용성·정책활용성** | 결론이 **보건복지부 고시 개정 제안**으로 직결. 공고문의 *"정책제안"* 문구에 가장 정확히 대응하는 안 |
| **완성도·발표** | 지도 기반 시각화 → "여기가 제도의 사각지대입니다"를 한 장면으로 전달. 5분 영상 구성이 쉽다 |

### A-8. 팀원 원안의 우려를 어떻게 해소하는가

| 원안의 결함 | A안에서의 해소 |
|---|---|
| ① 검색량 ≠ 제도 결함 (인과관계 부재) | 인과 주장을 검색량에 걸지 않는다. 인과의 근거는 **행정 데이터로 측정한 공급-수요 괴리**. 검색량은 [7]단계의 **보조 검증 신호**로만 사용 → 인과 부담에서 해방 |
| ② 데이터랩이 상대 지수만 제공 | 순위 산정을 검색량에 의존하지 않으므로 무관해짐. 검색 트렌드는 "이 지역에서 시간에 따라 늘었는가"라는 **동일 키워드의 시계열 비교**로만 쓰며, 이건 상대 지수로도 타당한 용법 |
| ③ 발견이 아니라 확인 구조 | **[6]단계가 순수한 발견이다.** 어느 지역이 나올지 분석 전에는 알 수 없다. 결과가 곧 새로운 정보 |
| ④ 정답 라벨 부재 → 검증 불가 | 공식 지정 111개 시군구가 정답 라벨. 성능 지표 제시 가능 |
| ⑤ 데이터 규모가 작음 | 10만 기관 원자료 + 전국 공간 데이터로 규모 해결 |

> **팀원 설득 논리**: "네 아이디어를 버린 게 아니다. 목표(제도의 사각지대 발견)는 그대로 두고,
> 근거를 검증 가능한 것으로 바꿨다. 검색 데이터도 실제로 쓴다 — 다만 주장의 유일한 기둥이 아니라
> 보조 증거로."

### A-10. 왜 소아청소년과를 권하는가

- 대상 인구(0~14세) 정의가 명확해 수요 지표에 논란의 여지가 없다
- "소아과 오픈런"은 도시에서 발생하는 현상 → **도시형 취약지 가설과 정확히 맞물린다**
- 사회적 관심도가 높아 발표 시 심사위원의 즉각적 공감을 얻는다
- 검색 트렌드 보조 신호를 붙이기에 가장 자연스럽다

## B안: 폭염 취약계층 사각지대 (시의성 최고)

### B-1. 핵심 발상

> 무더위쉼터는 **개수**로 관리된다. 그러나 폭염 취약계층(고령·독거)의 실제 이동 반경은 도보 5~10분이다.
> **"행정동에 쉼터가 몇 개 있다"와 "우리 집에서 갈 수 있는 쉼터가 있다"는 전혀 다른 문제다.**

즉 A안과 동일한 구조 — **행정 지표(개수)와 실질 접근성(도달 가능성)의 괴리** — 를 폭염 도메인에 적용한 것.

### B-2. 데이터

| 역할 | 데이터 | 출처 |
|---|---|---|
| 공급 | 전국무더위쉼터표준데이터 (시설구분, 주소, 면적, **이용가능인원**, **냉방기 보유 여부**) | [data.go.kr/15013199](https://www.data.go.kr/data/15013199/standard.do) |
| 노출 | 기상청 ASOS/AWS 기온 관측 | 기상자료개방포털 |
| 취약 | 읍면동 고령인구·독거노인, 건물 노후도, 녹지 비율 | 행안부 / 건축물대장 / 환경공간정보 |
| **결과 검증** | 질병관리청 온열질환 응급실감시체계 (지역별·일별) | [data.go.kr/15149889](https://www.data.go.kr/data/15149889/fileData.do?recommendDataYn=Y) |

### B-3. 이 안만의 강점

- **표준데이터에 `이용가능인원`, `냉방기 보유` 컬럼이 있다** → 단순 개수가 아닌 **실질 수용력** 평가 가능.
  "쉼터로 등록돼 있지만 에어컨이 없다" 같은 발견이 나올 수 있고, 이건 그 자체로 강력한 정책 메시지다.
- **온열질환 감시 데이터가 결과 지표(outcome)** 역할 → 준(準)정답 라벨 확보.
  "우리가 사각지대로 판정한 지역에서 실제 온열질환 발생률이 높다"를 보이면 검증 성립.
- **8월 심사라는 시점** — 폭염이 한창일 때 폭염 분석을 발표한다. 시의성 점수는 압도적.
- 데이터가 전부 표준데이터/공개 통계라 전처리 부담이 A안보다 낮다.

### B-4. 약점

- 온열질환 감시 데이터의 공간 단위가 **시도 또는 시군구 수준일 가능성**이 높다.
  읍면동 단위 사각지대 분석의 검증으로 쓰기엔 해상도가 부족할 수 있다. → **실물 확인 필수**
- A안처럼 "공식 지정 목록"이라는 깔끔한 이진 정답 라벨이 없다.
  검증이 상관관계 수준에 머물 위험.
- 유사 분석(무더위쉼터 접근성)이 지자체 보고서 형태로 이미 존재한다. 창의성 차별화 포인트를 별도로 만들어야 함
  (→ `이용가능인원`·`냉방기` 기반 실질 수용력이 그 차별화 지점).

## C안: 상권 폐업 위험 조기경보

### C-1. 구성

| 항목 | 내용 |
|---|---|
| 데이터 | [서울시 상권분석서비스](https://data.seoul.go.kr/dataList/OA-15572/S/1/datasetView.do) — 추정매출/점포/유동인구/집객시설/상주인구 등 복수 테이블, 분기별 수십만 행 |
| 라벨 생성 | 분기 간 점포 수 변화로 폐업 라벨 자동 생성 |
| 모형 | XGBoost 다음 분기 폐업 위험 예측 |
| 해석 | SHAP 요인 분석 |
| 검증 | 시계열 홀드아웃 (과거 분기 학습 → 최신 분기 예측) |

### C-2. 평가

**강점**
- 데이터 규모가 세 안 중 가장 크다 (진짜 "빅데이터" 규모)
- 라벨이 데이터에서 자동 생성되므로 검증 설계가 가장 깔끔하고 확실하다
- 전처리·모델링 난이도가 예측 가능해 **17일 내 완주 실패 위험이 가장 낮다**

**치명적 약점**
- **유사 프로젝트가 극도로 흔하다.** 서울시 상권분석 데이터는 국내 데이터 공모전의 사실상 표준 소재이며,
  "폐업 예측 + SHAP" 조합은 수없이 반복된 구성이다.
- 공고문이 반복 강조하는 **"창의성"** 에서 가장 불리하다.
- 정책 제안 연결도 약하다 (결론이 "이 상권은 위험하니 창업하지 마세요" 수준에 머물기 쉬움).

### C-3. 이 안의 실제 용도

C안은 **본안이 아니라 안전망(fallback)** 으로 두는 것이 맞다.
A안 또는 B안의 데이터 검증이 8/1까지 실패할 경우, 남은 기간에 확실히 완주할 수 있는 대안으로 보유한다.

## 최종 권고

> **A안 채택. 단, 진료과목을 소아청소년과 1개로 좁힌다.**
> **B안은 A안의 데이터 검증 실패 시 1순위 대안, C안은 최후 안전망으로 보유한다.**

**근거 요약**
1. 세 안 중 **창의성과 정책 제안 연결이 동시에 최상**인 유일한 안
2. 공식 지정 목록이라는 **명확한 정답 라벨**을 확보 — 팀원 원안의 최대 결함(검증 불가)을 정면 해결
3. 문제의 실재를 **언론·국회 자료로 뒷받침** 가능 → "왜 이 주제인가"에 대한 답이 준비돼 있음
4. 팀원의 문제의식(제도의 사각지대 발견)을 폐기하지 않고 계승 → 팀 내 합의가 쉽다
5. 유일한 약점인 완주 리스크는 **진료과목 축소**로 통제 가능

## 공통 주의사항 (주제 무관, 반드시 지킬 것)

**제출물 관련**
- **계획서 PPT와 결과 보고서 PPT는 별개 제출물**이다. 계획서 = 문제정의·방법·범위, 결과 보고서 = 수행과정·결과·제언.
  하나를 복사해 제목만 바꾸면 감점 요인이다.
- 결과 보고서는 **인쇄본 1부**도 함께 제출해야 한다. 컬러 인쇄 시간 확보 필요.
- 영상은 **5분 내외** — 초과하면 감점 가능. 대본을 미리 써서 분량을 맞출 것.
- 제출은 **방문만 가능하며 우편 불가**. 8/14 17:00 마감이지만 오전 중 제출 권장.

**소스코드 관련 (심사위원이 실행해 볼 수 있어야 한다)**
- 절대경로 하드코딩 금지 → 상대경로 사용
- `requirements.txt` 또는 `environment.yml` 포함
- 실행 순서를 명시한 `README.md` 포함
- 원본 데이터도 함께 제출 (재현 가능성)

**데이터 윤리**
- 모든 데이터의 출처와 라이선스(공공누리 유형) 명기
- 집계 데이터만 사용, 개인 식별 정보 미포함 — 보고서에 명시하면 신뢰도 가점
- 네이버 데이터랩 API 사용 시 이용약관 및 호출 한도 준수

**분석 관련**
- 상관관계를 인과관계로 서술하지 말 것 (팀원 원안이 걸린 함정 — 보고서 전체에서 경계)
- 모형 성능은 반드시 **홀드아웃 또는 교차검증** 결과로 제시
- "왜 이 방법을 썼는가"를 각 단계마다 한 줄씩 명시 → 발표심사 질의 대비
