# B안 재설계 — 서울 폭염 사각지대 (2026-07-29)

> 실제 API 호출로 검증 완료. **B안은 처음 평가보다 훨씬 강하다.**
> 앞선 검토에서 지적한 약점(정답 라벨 부재, 온열질환 해상도 부족)이 **둘 다 해소되었다.**

## 1. 게임체인저 ① — S-DoT 도시데이터 센서 `IotVdata017`

**701,240건** · 시간 단위 실측 · 서울 전역

| 컬럼 | 값 예시 | 의미 |
|---|---|---|
| `MSRMT_HR` | `2026-07-28_23:07:00` | **시간 단위 측정** |
| `CGG` / `DONG` | `Gangbuk-gu` / `Mia-dong` | **자치구 · 행정동** |
| **`RGN`** | `traditional_markets` | **설치 지점 유형** |
| **`MAX_TP`/`AVG_TP`/`MIN_TP`** | 29.6 / 29.5 / 29.4 | **실측 기온** |
| `MAX_HUM`/`AVG_HUM`/`MIN_HUM` | 76 / 75 / 75 | 습도 |
| `MAX_UV`/`AVG_UV` | 0.0 | 자외선 |
| 조도·소음·진동 | | 부가 지표 |

`RGN` 관측값: `traditional_markets`, `public_facilities`, `residential_area`, `main_street`

> ### 왜 이게 결정적인가
> 기상청 ASOS는 서울에 관측소가 **극소수**다. 그래서 기존 폭염 분석은
> "서울 전체가 33도"처럼 뭉뚱그릴 수밖에 없었다.
>
> S-DoT은 **행정동 단위, 시간 단위, 설치 유형별 실측 기온**을 준다.
> → **도시 열섬(UHI)의 미시 구조를 그릴 수 있다.**
> → 같은 자치구 안에서도 **전통시장 vs 주거지역 vs 대로변**의 기온 차이를 잡아낸다.
> → 기온 + 습도가 있으므로 **체감온도(열지수, Heat Index)** 를 직접 산출할 수 있다.

**⚠️ 결측 있음**: 샘플에서 성수1가1동 기온이 빈 값이었다. 풍속·풍향은 대체로 결측.
→ 결측 처리가 필요하며, **이 과정 자체가 평가기준 항목②(30점) 전처리 득점 요소**다.

## 2. 게임체인저 ② — 온열질환 감시 데이터

[질병관리청 온열질환 감시 데이터](https://www.data.go.kr/data/15149889/fileData.do)

| 항목 | 내용 |
|---|---|
| 건수 | **90,691건** — **집계가 아니라 개별 환자 단위** |
| 기간 | 2011 ~ 2025 (14년) |
| 공간 단위 | **발생시도 + 발생시군구** ← 시군구 확보 |
| 시간 | **발생일자** (일별) |
| 속성 | 성별, 나이, **실내외구분**, **발생장소** |
| 다운로드 | **로그인 없이 즉시 가능** |

> ### 앞선 우려가 해소되었다
> 나는 이전 검토에서 *"온열질환 데이터가 시도 단위일 가능성이 높아 검증 해상도가 부족하다"*
> 고 적었다. **틀렸다. 시군구 단위이고, 그것도 개별 환자 레코드다.**
>
> 더 중요한 건 **`실내외구분`과 `발생장소`** 다.
> **실내(특히 집)에서 발생한 온열질환만 추출하면 = 냉방 취약계층을 정확히 겨냥할 수 있다.**
> 논밭에서 일하다 쓰러진 사례와 집에서 에어컨 없이 쓰러진 사례는 완전히 다른 정책 문제다.
> 기존 폭염 분석 대부분이 이 둘을 섞어서 본다.

## 3. 무더위쉼터 `TbGtnHwcwP`

**4,021건** · **2026년 기준(최신)** · 서울

| 컬럼 | 값 예시 |
|---|---|
| `FACILITY_TYPE1` / `TYPE2` | 공공시설 / 복지·문화·체육시설, 특정계층시설 |
| `R_AREA_NM` | 성프란치스코장애인종합복지관 |
| `R_DETL_ADD` / `LOTNO_ADDR` | 도로명 / 지번 주소 |
| **`LON` / `LAT`** | **126.8905 / 37.4816** ← 위경도 완비 |
| `MAP_COORD_X/Y` | GRS80 중부원점 |
| `R_AREA_SQR` | 511.00 (면적) |
| `USE_PRNB` | 154.0 (이용가능인원) |

**⚠️ 정직한 확인**: 샘플 5건 중 **2건은 면적·정원이 결측**(빈 값 / 0.0)이었다.
앞서 "실질 수용력 평가"를 차별화 포인트로 밀었는데, **결측률에 따라 그 전략의 강도가 달라진다.**
→ 전수 다운로드 후 결측률을 먼저 확인할 것. 결측이 크면 **좌표 기반 도보 접근성**에 무게를 싣는다.
→ 좌표는 전 건 존재하므로 **접근성 분석은 확실히 가능**하다.

## 4. 재설계된 분석 구조

```
[1] 실측 폭염 노출도  ← S-DoT 70만 건
    행정동 × 일자별 최고기온 / 열대야 일수 / 체감온도(기온+습도)
    설치유형(RGN)별 기온차 → 도시 열섬 미시 구조

[2] 인구 취약성        ← 고령인구 · 독거노인 · 기초생활수급 · 건물 노후도
    IPCC 취약성 프레임워크: 위해(Hazard) × 노출(Exposure) × 취약성(Vulnerability)
                            − 적응능력(Adaptive Capacity)

[3] 쉼터 실질 접근성   ← 무더위쉼터 4,021개 좌표
    고령자 도보 반경(400~500m, 5~10분) 기준 커버리지
    ※ 행정동에 쉼터가 "몇 개 있다"가 아니라 "우리 집에서 갈 수 있다"로 측정

[4] 사각지대 도출
    폭염 노출 高  ∧  인구 취약 高  ∧  쉼터 접근성 低

[5] 검증  ★ 여기가 핵심
    온열질환 발생 데이터(9만 건)로 대조
    특히 실내(집) 발생 사례만 추출 → 냉방 취약 신호
    "사각지대로 판정한 곳에서 실제로 실내 온열질환이 더 발생하는가?"

[6] 정책 제안
    쉼터 신규 배치 우선순위 (max-coverage 최적화)
    냉방기 미보유 쉼터 우선 개선 목록
```

## 5. 평가기준 대조

| 항목 (배점) | B안의 대응 |
|---|---|
| ① 계획·**이론적 고찰** (30) | **IPCC 기후 취약성 프레임워크**(Hazard×Exposure×Vulnerability−Adaptive Capacity), **도시 열섬(UHI)** 이론, 폭염 초과사망 연구 → 학술 근거 확보. 다만 A안의 "고시 원문 + 언론 지적"만큼 **직접적이진 않다** |
| ② 수집·전처리·**EDA** (30) | S-DoT 70만 + 온열질환 9만 + 쉼터 4천 + 인구. **결측 처리, 좌표 공간조인, 체감온도 산출** → 전처리 서사 풍부 |
| ③ 분석 (20) | 공간 클러스터링, 커버리지 최적화, 발생률 회귀 |
| ④ 창의성·완성도 (20) | 실측 센서 기반 미시 열섬 + 실내 발생 분리 → 차별화. **8월 심사 시의성 최상** |

## 6. A안과의 비교 — 솔직한 평가

| | **A안 (의료취약지)** | **B안 (폭염)** |
|---|---|---|
| 정답 라벨 | **공식 지정 Y/N (이진, 명확)** | 온열질환 발생률 (연속, 준라벨) |
| 검증 강도 | **강** — 분류 성능 지표 산출 가능 | 중 — 상관관계 중심 |
| 이론적 고찰 | **최상** (고시 원문·통계·언론) | 상 (IPCC·UHI 이론) |
| 데이터 규모 | 100만+ 행 | **80만+ 행** |
| 데이터 검증 상태 | **완료 + 가설 입증까지** | **완료** (가설 검증은 미실시) |
| 공간 해상도 | 시군구 (250) | **행정동 (약 425)** ← 더 세밀 |
| 시의성 | 중 | **최상 (8월 심사)** |
| 지도 시각화 | 상 | **상** (열지도 + 커버리지) |
| 핵심 리스크 | 없음 (검증 완료) | 쉼터 정원 결측률 미확인 |

### 판단

> **A안이 여전히 앞선다.** 이유는 단 하나 — **정답 라벨의 성격**이다.
> A안은 "정부가 지정한 111개"라는 **이진 정답**이 있어 분류 모형의 정밀도·재현율을 제시할 수 있다.
> B안은 온열질환 발생률이라는 **연속형 준라벨**이라 검증이 상관관계 수준에 머문다.
>
> 그리고 A안은 이미 **파일럿에서 핵심 가설이 정량 입증**되었다. B안은 아직 그 단계가 아니다.
>
> **다만 B안은 명백히 살아났다.** 처음 평가("정답 라벨 없음, 해상도 부족")는 틀렸다.
> 시의성과 공간 해상도에서는 A안보다 낫다.

### B안을 선택한다면 조건

- **8/1까지 온열질환 데이터로 신호가 보이는지 먼저 확인**할 것
  (사각지대 후보 지역의 실내 온열질환 발생률이 실제로 높은가)
- 그 신호가 약하면 A안으로 즉시 전환
- A안은 이미 검증이 끝나 있으므로 **언제든 되돌아갈 수 있다**
