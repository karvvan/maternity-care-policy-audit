대표자 질의응답(8/8)에서 나온 의문점·설명 필요 지점. **통합 최종보고서 작성 시 전부 반영할 것.**
각 항목은 심사 Q&A에서도 나올 수 있는 질문이므로, 본문 서술 또는 한계·부록에 선제 배치한다.

> **2026-08-10 전수 검증 완료**: 16항목 전부 결과보고서 v2 반영을 키워드 자동 대조로 확인. 미결은 15번(조원 노트북 셀 수정 — 조원 액션 대기) 하나.

## A. 서술 수위 조정 (과장 방지)

- [x] **1. 재현율 99.4%의 해석**: "숨은 규칙을 역산으로 발견"이 아니라 **"공표된 고시 기준의 데이터 검증"**으로 서술.
  - 판정식은 고시·지침에 공표된 기준이며, 우리 기여는 "실제 지정 결과와 158/159 일치함을 확인"한 것.
  - 불일치 4건(완도·정선·안성·이천) = 판정식 위에 행정적 선별 층이 존재하는 증거 → "2개 지표로 완결" 단정 금지.
  - "공급을 안 본다"는 별도 검증(로지스틱 AUC 무변화, 공급 최하위 15곳 지정 0곳)으로 뒷받침.
- [x] **2. A안 분만 사각지대 8곳의 수위 조정**: 계룡·장성·예천은 분만 사업 체계에서 **C등급으로 이미 인지**됨(외래·순회 자격 있음).
  - "제도 밖" 주장은 의왕·과천·광주시·울주·울산 북구(등급 체계에도 없음)에만 적용.
  - `의료취약지.csv` 이진 라벨과 사업 공고 A/B/C 등급은 서로 다른 체계임을 본문에 명시.

## B. 개념 설명 박스 (본문 삽입)

- [x] **3. TRI 정의 상세**: 이동시간 기준(자가용+대중교통 GIS), 병원 내 대기시간 무관, "60분 **이내**에서 이뤄진 이용 비율"(높을수록 양호), 분모=주민 총 이용, 자료원=건보 청구 DB(행태 실측).
- [x] **4. 접근성(이론값·지도 계산) vs TRI(행태값·실측) 구분**과 AND 이중검증을 쓰는 이유(각 지표 단독의 오판 가능성).
- [x] **5. TRI의 관내/관외 무구분** = A안 사각지대 발생 메커니즘 (기존 §6.6 유지·강화).
- [x] **6. A/B/C 등급 체계 해설**: A=이중 충족(32), B=단일 충족(21), C=잔여 범주(55).
  - C는 취약도 서열이 아니라 **자격표**: ① 가임 배경인구 미달형(분만실 자생 불가) ② 분만 지원 기수령형(운영지원 자격 유지용 졸업반). 두 유형의 이질성 명시.
- [x] **7. 지역-병원 이원 구조**: 측정·등급=시군 단위 / 신청·선정·수령·평가=병원 단위. 신청주의(병원이 안 나서면 등급 무의미) → 1단계 미설명 분산의 구조적 원인.

## C. 방법론 방어 (한계 또는 본문)

- [x] **8. C등급 제외의 순환 논리**: "지원받으면 C가 된다" → 종속변수가 집단 정의에 누출. C 포함 ρ=0.011(희석) vs A·B 한정 ρ=+0.381 대비를 본문에 명시. (비유: 장학금 받으면 장학반 배정 → 장학반으로 장학금 설명 불가)
- [x] **9. 선호 원정 교란 — 미충족분만은 상한 추정치**: 60분 밖 출산에 "못 가서"와 "안 가서(대형병원 선호)"가 섞여 있어 분리 불가. 한계에 신규 항목으로 추가.
  - 방어 3종: ① AND 조건상 선호 단독으로는 취약 판정 불가 ② B등급 이용률취약형 17곳 중 16곳 관내 수행 0건(관내 선택지 부재는 사실) ③ 정부 스스로 B등급 "취약" 판정한 지역임(우리 판정 아님).
  - A안 쪽 방어: 동급(의원+병원+종합) 유출 분리 통제, 위성도시형/군 지역형 생활권 구분.
- [x] **10. "60분 내 인접 도시 가능하면 취약 아님 아닌가" 정면 반론 처리** (§ '취약의 정의' 논쟁 섹션 신설):
  - 현행 정의(도달 가능성)에서는 맞는 말임을 인정하고 시작.
  - 반론 근거: ① 분만은 이벤트가 아니라 과정(산전진찰 10여 회+산후+신생아, 관내 0이면 전 과정 원정) ② 정부 지침 스스로 "분만실 없는 지역"(장성 포함 54곳)을 사업 배경의 문제로 규정 — 판정식과 지침 서사의 내적 긴장 ③ 지역 소멸 악순환(지침 추진배경 인용) ④ 3분야 동시 공백(생활 전반의 의료 공동화).
  - 균형: 소규모 분만실 난립은 임상 안전상 역효과(연 50건 기준의 취지) → **지정 ≠ 분만실 설치**. 유형 배정(설치/운영/외래/순회)이 답 — 조원안 2단계와 접속.
- [x] **11. 역인과·시점 불일치**(기지원 2011~2025 누적 vs 지표 2023): 기존 한계 유지, 가능하면 지원 개시 연도별 분리 검토.
